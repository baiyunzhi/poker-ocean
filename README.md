# 螺纹钢 · 均线聚散系统 · 回测工具

基于 MA20/MA60/MA120 均线聚散策略的螺纹钢期货回测引擎。零外部依赖，仅需 Python 标准库。

## 文件说明

| 文件 | 用途 |
|------|------|
| `backtest_rebar.py` | 回测引擎主程序，含策略逻辑、回测引擎、统计报告 |
| `_fetch_data.py` | 从新浪财经下载 RB0（螺纹钢主力连续）日线数据 |
| `rb_daily.csv` | 日线数据文件（2009-03 ~ 至今），回测默认读取此文件 |
| `strategy_params.md` | 策略参数文档（入场/离场/止损/资金管理规则） |

## 快速开始

```bash
# 下载最新数据（需要外网）
python _fetch_data.py

# 跑回测（默认宽松参数）
python backtest_rebar.py --data rb_daily.csv

# 原始严格参数
python backtest_rebar.py --data rb_daily.csv --strict
```

## 策略概要

**核心逻辑**：均线聚散（Convergence/Divergence）
1. 均线多头/空头排列确认方向
2. 偏离度收缩至 ≤2.5% 持续 N 日（聚合/震荡）
3. 偏离度反弹至 2-5% 区间（发散初期，趋势启动）
4. 价格创新高/新低 + 成交量放大 确认入场
5. MA120 方向一票否决

## 参数对比

| 参数 | 宽松（默认） | 严格（--strict） |
|------|------------|----------------|
| 聚合天数 | ≥3 日 | ≥5 日 |
| 发散区间 | 2.0% ~ 5.0% | 2.5% ~ 4.0% |
| 放量倍数 | ≥MA20均量×1.2 | ≥MA20均量×1.5 |
| 新高回溯 | 15 日 | 20 日 |

## 用法

```bash
python backtest_rebar.py [选项]

选项：
  --data, -d FILE       CSV 数据文件路径
  --sample, -s N        生成 N 根示例 K 线（默认 550）
  --capital, -c AMOUNT  起始资金（默认 10,000）
  --strict              原始严格参数
  --debug               显示每日信号诊断
  --no-chart            不显示资金曲线图
```

## 数据源

- **接口**：新浪财经 `InnerFuturesNewService.getDailyKLine`
- **品种**：RB0（螺纹钢主力连续合约）
- **字段**：日期、开盘价、最高价、最低价、收盘价、成交量、持仓量
